# 차곡차곡 가계부

용돈 안에서 쓰면 돼지 저금통에 동전이 차곡차곡 쌓이는 개인 가계부예요.
아이폰 결제 문자가 오면 자동으로 기록되고, 노트북과 폰에서 같은 기록을 봐요.

## 파일
- `index.html`: 앱
- `apps-script/Code.gs`: 구글 시트 저장소 (Apps Script에 붙여 넣는 코드)
- `manifest.webmanifest`, `icons/`: 홈 화면에 앱처럼 설치
- `sw.js`: 앱을 빨리 열기

비밀번호와 웹 앱 주소는 이 저장소에 넣지 않아요. 기기마다 앱 설정에서 입력해요.

## 1. 구글 시트 만들기
1. 구글 드라이브에서 새 스프레드시트를 만들고 이름을 `차곡차곡`으로 바꿔요.
2. [확장 프로그램] → [Apps Script]를 열고, `apps-script/Code.gs` 내용을 통째로 붙여 넣고 저장해요.
3. 왼쪽 [프로젝트 설정](톱니바퀴) → 맨 아래 [스크립트 속성] → [속성 추가]
   - 속성: `PASSWORD`
   - 값: 내가 정한 비밀번호
4. 편집기로 돌아와 함수 목록에서 `setup`을 고르고 [실행] → 권한 허용.
   시트에 내역 / 저축 / 저축 목표 / 카드 결제 금액 / 정기 지출 / 특별 지출 / 문자함 / 카드 사진 / 설정 탭이 생겨요.
5. [배포] → [새 배포] → 유형 [웹 앱]
   - 실행: 나
   - 액세스 권한: 모든 사용자
   - [배포]를 누르고 나오는 **웹 앱 URL**(…/exec)을 복사해 둬요.

코드를 고친 뒤에는 [배포] → [배포 관리] → 연필 → 버전 [새 버전]으로 다시 배포해야 반영돼요.

## 2. GitHub Pages로 올리기
1. GitHub에서 새 저장소를 만들어요 (예: `chagok`).
2. 이 폴더의 파일을 모두 올려요.
3. 저장소 [Settings] → [Pages] → Branch `main`, 폴더 `/ (root)` → [Save].
4. 1~2분 뒤 `https://<아이디>.github.io/chagok/` 에서 열려요.

## 3. 앱 연결
1. 앱 [설정] → [구글 시트 연결]에 웹 앱 URL과 비밀번호를 넣고 [연결하고 동기화].
2. 노트북, 폰 각각 한 번씩 해 주세요.
3. 아이폰: Safari로 열고 공유 버튼 → [홈 화면에 추가].

## 4. 아이폰 결제 문자 자동 기록 (단축어)
1. 단축어 앱 → [자동화] → [+] → [메시지]
2. '메시지 포함'에 `승인` → [즉시 실행] 선택 → [다음]
3. [새로운 빈 자동화] → 동작 [URL 내용 가져오기]
   - URL: 웹 앱 URL
   - 방법: POST
   - 요청 본문: JSON, 항목 3개
     - `action` (텍스트): `sms`
     - `pw` (텍스트): 비밀번호
     - `text` (텍스트): 변수 [단축어 입력] → '메시지'를 고르세요
4. 결제 문자가 오면 시트 '문자함'에 쌓이고, 차곡차곡을 열 때 읽어서 기록돼요.

카드사마다 문자 모양이 달라요. 앱 [설정] → [결제 문자 읽기 시험]에 실제 문자를 붙여 넣어 확인하고,
카드를 못 알아보면 그 카드의 '문자에서 알아볼 단어'를 고쳐 주세요.

## 계산 방법
- 월급(자동 계산): 시급 × 하루 근무시간 × 근무일 수 + 주휴수당 − 공제
  - 근무일 = 급여 기간(기본: 지난달 1일~말일)의 일하는 요일 − 평일 공휴일 − 쉰 날·결근
  - 공휴일 목록은 index.html의 HOLIDAYS에 2026~2027년이 들어 있어요. 해가 바뀌면 추가해 주세요
  - 주휴수당 = (주 근무시간 ÷ 40) × 8시간(최대) × 시급, 주 15시간 이상일 때. 급여 기간 안의 일요일마다 한 주, 결근한 주는 빠짐
  - 월급날이 주말·공휴일이면 앞 평일에 받는 걸로 계산 (설정에서 미루기·그대로도 가능)
  - 실제로 받은 금액을 적으면 그 달은 그 금액을 쓰고, 다음 달 예상은 최근 3번의 '받은 금액 ÷ 계산값' 평균을 곱해 보정
  - '공휴일도 돈을 받아요'를 켜면 평일 공휴일도 시급을 받는 걸로 계산 (5인 이상 사업장)
- 이번 달 쓸 돈 = 한 달 용돈 합계 (+ 월급에서 생활비로 보탤 돈, 설정한 경우) − 정기 지출(고정비·구독) − 그 달 특별 지출(선물, 병원비처럼 한 번 크게 나가는 돈)
- 하루 예산 = 이번 달 쓸 돈 ÷ 그 달 날짜 수
- 하루 예산 안에서 쓴 날은 '예산 지킨 날'로 기록돼요
- 실제 결제 내역 중 카테고리가 '고정비·구독', '특별 지출'인 것은 하루 예산에 넣지 않아요 (미리 빼 뒀으니까)
- 신용카드·소액신용으로 쓴 돈도 쓴 날 바로 이번 달 쓸 돈에서 빼요 (다음 달 용돈에서 미리 쓴 돈이라서)
- 결제 금액만 적기: 내역을 다 못 적은 달은 카드사 결제 금액만 넣으면, 그 이용기간에 이미 적은 내역을 빼고 남는 금액을 그 달 지출('카드 합계')로 더해요. 결제 예정액도 그 금액으로 보여요
- 교통비 환급: 내역 화면에서 받은 환급(몇 월분, 어디로 받았는지)을 적으면 받은 달 지출에서 빠져요. 설정의 환급률로 다음 달 환급을 예상해요 (택시·KTX·시외버스 제외)
- 저축 방법: 적금·예금·파킹·외화·주식·청약·기타. 외화는 통화, 산 외화, 적용 환율을 적으면 원화로 바꿔 기록
- 오늘 환율: 저축 화면을 열 때 하루 한 번 open.er-api.com(ExchangeRate-API)에서 불러와요(안 되면 jsDelivr의 currency-api). 환율 우대 100% = 매매기준율이라 이 기준 환율을 그대로 써요. 은행 매매기준율과 몇 원 차이가 날 수 있어요
- 카드 결제 예정액: 카드별 결제일과 이용기간으로 계산
  - 하나 13일: 지난달 1일 ~ 말일 사용분
  - 우리·신한 11일: 전전달 28일 ~ 지난달 27일 사용분 (소액신용만)
